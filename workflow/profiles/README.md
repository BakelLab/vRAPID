# vRAPID Workflow Profiles

The `profiles` directory within the `vRAPID` repository contains an example configuration file that define specific execution profiles for the pipeline. Currently, the profile `config.yaml` is specific for an `LSF` cluster.

## Custom Profiles

Users can create custom profiles to suit their specific computational environments. To do so, copy an existing profile and modify the configuration files as needed. Ensure that all necessary parameters are defined to facilitate smooth execution within your environment.
